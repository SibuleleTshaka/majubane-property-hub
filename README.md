# Majubane Property Hub

Build a modern, professional real-estate management website/app called “Majubane Properties”, directed by Bamanye Majubane.

Contact:
Email: bamanyemajubane@gmail.com
Location: Port Elizabeth, Eastern Cape, South Africa.

Use the uploaded Majubane Properties logo throughout the website. EXACTLY match its colours: bright red (#EA2828), bright blue (#28AAE6), white and dark charcoal text. Do not change the logo.

Design inspiration: a clean, professional property marketplace/admin experience inspired by Private Property, with property cards, search, filters and modern responsive design. Do NOT copy their branding or exact design.

Pages/features:
1. Dashboard – properties, clients, enquiries, tasks, follow-ups and notifications.
2. Properties – search/filter by location, price, bedrooms, bathrooms, property type and Sale/Rent.
3. Clients – profiles, requirements, enquiries and communication history.
4. AI Assistant – simple chat box for property and admin questions.
5. AI Email Assistant – generate professional emails, replies and follow-ups.
6. AI Summariser – summarise emails, meetings and documents into key points, actions and deadlines.
7. Task Planner – create, prioritise and track daily/weekly tasks.
8. Enquiries – manage buyer/renter enquiries and follow-ups.

Make the interface very easy to use with a simple sidebar, search bar, dashboard cards, notifications and clear buttons. Responsive on desktop and mobile.

Add responsible AI notices: AI-generated content must be reviewed by a human before being sent to clients.
Use realistic South African property examples and clearly label demo listings.
